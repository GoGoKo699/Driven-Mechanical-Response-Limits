# Provenance

The canonical scientific account is in `docs/`, not in the sequence of exploratory notes. `INPUTS.json` fingerprints the supplied archives and latest derivation notes without republishing unrelated scouting material or recursively nesting historical packages.

`checks/network.py` and `checks/springs.py` retain the supplied round-four and round-five scientific code byte-for-byte. Their hashes are verified by the documentation checker. Earlier source archives were run on disposable copies during consolidation; those runs did not overwrite their reference files.

This is a standalone mechanics repository. Its scientific assumptions, teaching route, and publication arrangements are not inherited from a separate project. No contact or manuscript-hold wording has been added by analogy with another repository.
